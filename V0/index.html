01

AGENT SYSTEM · PROJECT

Business Travel Assistant Agent

A multi-agent travel assistant that combines preference memory, enterprise knowledge retrieval, real-time search, and itinerary generation.

  • 90%+intent accuracy
  • 15sresponse time
  • 85%cache hit rate

I redesigned intent routing for six intent categories, introduced priority-aware parallel scheduling, and built short- and long-term preference memory with Redis caching. I also developed a Milvus and BGE-M3 RAG pipeline for travel policies, city guides, and FAQs, with source-aware retrieval.

Python · Multi-Agent Orchestration · Milvus · BGE-M3 · Redis · RAG

02

AUTOMOTIVE AI · HUAWEI INTERNSHIP

Intelligent Automotive Q&A Assistant

A document-grounded assistant for car buying, driving, troubleshooting, maintenance, and insurance questions, with multi-turn topic memory.

Project scope Documents → RAG → LoRA Evaluation results to be added after a measured comparison

I built a JSON instruction dataset with instruction, input, and output fields across direct answers, step-by-step guidance, fault analysis, terminology, and safety or insurance reminders. I built a RAG application using uploaded owner manuals, maintenance guides, diagnostic documents, and insurance terms for grounded multi-turn answers. I then applied LoRA adaptation to an open-source model and compared outputs before and after fine-tuning and RAG.

Automotive documents · JSON dataset · RAG · Multi-turn memory · LoRA

DATA ANALYSIS · INTERNSHIP

Credit Overdue Risk Prediction

A risk-modelling workflow that joined transaction, order fulfilment, behaviour, and text-derived features into a consistent analytical dataset.

0.74 ROC-AUC after feature iteration and tuning

During my data analyst internship at JD Finance, I used SQL and Excel for data extraction and cleaning, transformed unstructured notes into model features, and trained and tuned a LightGBM classifier in Python. I evaluated it with accuracy, F1-score, and ROC-AUC.

Python · SQL · Excel · NLP · LightGBM
